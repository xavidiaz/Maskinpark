## Lärdomar och fallgropar

- **`dotnet watch` måste köras i serverprojektet.** Körs det i
  `Maskinpark.Client` startar `WasmAppHost` (statisk filserver) och `/` ger
  404 — Client har ingen startsida, den ligger på servern (`App.razor`).
  Från rotmappen: `dotnet watch --project Maskinpark`
- `dotnet watch` i roten fungerar inte — en `.sln` går inte att *köra*
  (`dotnet build` fungerar däremot)
- Default launch profile = första i `launchSettings.json` (`http`,
  `localhost:5192`). `--launch-profile https` → `localhost:7116`
- `cmd1 && cmd2` — `cmd2` körs bara om `cmd1` lyckas. Ctrl+C på
  `dotnet watch` = fel-exit → https-kommandot kördes aldrig
- Överstruket `https` i webbläsaren = dev-certifikatet är inte betrott. Ofarligt
  lokalt
- `Failed to determine the https port for redirect` — `UseHttpsRedirection()`
  med http-profilen. Ofarligt
- `dotnet watch ❌ Failed to read '.../obj\Debug/...staticwebassets.development.json'`
  — SDK-bugg (bakstreck på Linux), [dotnet/sdk#54309](https://github.com/dotnet/sdk/issues/54309).
  Appen fungerar; vid utebliven CSS-hot-reload: Ctrl+R
- `git add` på borttagen fil stagar borttagningen. Glömt? `git commit --amend
  --no-edit` — bara innan push
