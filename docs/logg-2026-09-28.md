## Lärdomar

### Projektstrukturen
- Labben (PDF) säger bara "Blazor Web App" — **två projekt** är en följd av
  *Interactive render mode: WebAssembly*. Render mode Server hade gett ett
- `Maskinpark` = värd: serverar WASM-filerna + förrenderar. Ingen backend-logik
  förrän Fas 13. `Maskinpark.Client` = själva appen
- Syns i `.csproj` (`Sdk.Web` vs `Sdk.BlazorWebAssembly`) och `Program.cs`
  (`WebApplication` vs `WebAssemblyHostBuilder`)
- Servern har `Components/Pages/`, Client har `Pages/` i roten — servern är
  ett vanligt ASP.NET Core-projekt där `Pages/` är reserverat för Razor Pages
- Razor = syntax (2010), Blazor = ramverk (Browser + Razor). `.razor` =
  Blazor-komponent, `.cshtml` = MVC/Razor Pages
- Man skriver inte WebAssembly — man skriver C#/Razor, .NET-runtime körs som
  WASM i webbläsaren

### Blazor
- **Komponentnamn = filnamn**, skiftlägeskänsligt. `Navbar.razor` ≠
  `<NavBar>` → RZ10012 i `dotnet build` (okänt element)
- Ny mapp = nytt namespace → behöver `@using` (eller `_Imports.razor`)
- **CSS isolation:** `NavMenu.razor.css` gäller bara element som `NavMenu`
  själv renderar. Markup som flyttas till en annan komponent tappar stilen
- `[Parameter]` måste vara en `public` *property* (`{ get; set; }`), inte ett
  fält — annars runtime-fel "does not have a property matching the name"
  (syns i `dotnet watch`-terminalen, inte i build)
- Attributnamnet = barnets parameternamn: `OnSendData="SendData"` — vänster
  barnets händelse, höger förälderns metod
- `EventCallback` är en parameter som föräldern fyller i. Barnet anropar
  `InvokeAsync(m)`; lambdan `() => ...` fångar `m` från `@foreach`
- Efter en EventCallback rerenderar föräldern → alla barn får nya parametrar →
  `MachineStats` räknar om utan att veta om knappen
- `=>` (property) räknas vid varje läsning; `=` (fältinitierare) en gång.
  Fältinitierare kan inte referera andra instansfält (CS0236)
- En komponent kan ha flera `@page`-direktiv
- `href="dashboard"` (relativt `<base href>`) i stället för `/dashboard`
- Klick innan WASM laddat klart gör ingenting (förrenderad HTML)

### C# / HTML
- `x = !x` växlar en bool. `!=` jämför, tilldelar inte
- `Random.Shared.Next(n)` → index 0..n-1
- Guard clause: `if (!machine.IsOnline) return;` överst i stället för hela
  metoden i en `if`
- Regel i föräldern (säkerhet) + `disabled` i UI (feedback) — båda behövs
- `class` = identitet + förändring (maskin). `record` = värde (mätning)
- `<table>` för tabelldata (tillgänglighet, semantik), grid/flex för layout

### Git
- `git reset --hard HEAD` rör inte ospårade filer → `git clean -n` (torrkör)
  sedan `git clean -fd`. Säkrare: `git stash -u`
- `git add -A <mapp>` tar med borttagna filer
- `git reset --hard HEAD~1` bara för opushade commits — annars `git revert`
